# SKQD

Representative SKQD notebooks for Fig. 6 and Fig. 7 style initializer experiments.

Folders:
- `1D_XXZ`
- `1D_XXZ_X`
- `2D_XXZ`
- `2D_XYZ`

Before running SKQD notebooks, first run the corresponding generalization experiment folder to generate the required test data and model checkpoints. Copy or place those generated `.pt` and `.pth` files in the matching SKQD subfolder.

Each folder keeps one representative shot setting. Change `shots` for shot sweeps and `seed` for seed repeats.
